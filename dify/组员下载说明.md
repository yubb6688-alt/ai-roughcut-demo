# 视频评测：组员下载说明

## 云端导出版（全帧服务框架）

需要导入云端当前保存的工作流时，下载 [视频七维评测-云端导出版.yml](视频七维评测-云端导出版.yml)，在 Dify 工作室选择「创建 → 导入 DSL 文件」。这是从云端 Dify 导出的工作流当前保存版本，导出时未包含 Secret 值。

**当前状态：**工作流页面已显示发布；全帧处理服务的任务接口、鉴权和部署仍待完成，尚未做真实服务端到端联调。仅导入或发布这个 YML，不能完成全帧检测和评分。接入方式见 [全帧服务接口约定](FULL_FRAME_SERVICE_CONTRACT.md)，环境变量 `FULL_FRAME_BASE_URL` 和 `FULL_FRAME_API_KEY` 需在目标 Dify 环境单独配置。不要把密钥提交到仓库。

当前全帧原型按七个维度等权评分，和旧版的 21 个细项、20/20/15/15/10/10/10 权重不同；也尚未完整保留旧版的脚本逐项对照与修改建议。确定最终评分标准后仍需调整并重新测试。

## 其他文件是什么

| 文件 | 用途 |
| --- | --- |
| `video_review_qwen_2fps_cloud.yml` | 旧版云端抽样评测，每秒 2 帧；保留供参考，不是上面的云端全帧导出版本。 |
| `team_video_review_cloud.yml` | 另一套旧版云端抽样评测，评分规则和依赖与全帧框架不同。 |
| `team_video_review.yml` | 旧版本机辅助服务工作流，也是全帧工作流生成脚本的模板；不能单独作为全帧服务使用。 |
| `team_video_review_full_frame.yml` | 开发时生成的全帧工作流草稿；交付和导入以云端导出版为准。 |
| `full_frame_*.py`、`build_full_frame_workflow.py` | 给开发者参考的处理原型和生成代码；不是已部署的服务。 |
| `tests/` | 自动化测试，供开发与维护使用。 |

仓库中其他文件属于原有 AI 粗剪工作台，不是组员导入 Dify 所需的工作流文件。旧版本及原有项目文件保留以便查阅，避免误删依赖。
